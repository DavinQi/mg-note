# mg-note

macOS personal note-taking app. Notes live in your own GitHub or Gitee private repositories.

Built with Tauri 2, React, libgit2, and macOS Keychain.

## Develop

```bash
pnpm install
pnpm tauri:dev
```

## Package

```bash
pnpm package
```

Requires pnpm 10, Rust, and Xcode command line tools.
